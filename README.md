# The Getaway

Static fictional website prototype for the novel concept.

The public page is designed to feel like a legitimate travel and adventure brand, while the copy includes small narrative inconsistencies that can read differently after the story reveal.

## How to view

Open `index.html` in a browser.

## Static behavior

There is no backend, database, email delivery, analytics, external submission endpoint, or direct organizer contact channel. Registration is handled entirely in `script.js` with `event.preventDefault()` and a simulated success message. No visitor data is sent or stored.

## Files

- `index.html` - full static website structure
- `styles.css` - responsive visual design system
- `script.js` - mobile menu, client-side filters, FAQ behavior, and simulated form responses
- `images/` - local visual assets used by the page
